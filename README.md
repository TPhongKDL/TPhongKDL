### 1. Legal-HIL_RAG – Legal AI Assistant

**Hybrid Retrieval-Augmented Generation for Vietnamese Legal Documents**

Xây dựng hệ thống AI hỗ trợ tra cứu văn bản pháp luật và án lệ, tập trung vào kết hợp nhiều phương pháp retrieval và cải thiện chất lượng câu trả lời.

**Technical Highlights:**
- Hybrid Retrieval: Semantic Search + BM25.
- Reciprocal Rank Fusion (RRF).
- Cross-encoder / reranking architecture.
- Human-in-the-loop RAG workflow.
- Retrieval evaluation và answer verification.

**Technologies:** Python, LLM, RAG, Qdrant, Embeddings, BM25.

[View Repository](https://github.com/TPhongKDL/Legal-HIL_RAG)
